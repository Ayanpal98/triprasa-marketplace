# Security Policy

## Current scope
Triprasa is a static frontend prototype. It is not intended to collect or process real customer, seller, payment or order data.

## Reporting a concern
Please do not publish credentials, personal data or exploitable details in a public issue. Contact the project owner through a private channel with a concise description, reproduction steps and potential impact.

## Before production
A production release must include a threat model, dependency review (if dependencies are introduced), authentication and authorization review, input validation, secrets management, secure deployment configuration, backup/recovery planning, privacy review and payment-provider compliance checks where applicable.
