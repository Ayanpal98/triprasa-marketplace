# Contributing to Triprasa

Thank you for helping improve the Triprasa prototype.

## Before contributing
- Read README.md and PRODUCT_SPEC.md.
- Keep changes aligned with the community-first, indigenous-producer-first direction.
- Do not invent real sellers, prices, reviews, certifications, partnerships or impact numbers.
- Do not add community-sensitive stories, designs, names or imagery without documented permission.
- Never commit personal seller data, credentials, API keys or secrets.

## Suggested workflow
1. Open an issue describing the problem or proposed improvement.
2. Keep each change focused and small.
3. Test mobile and desktop widths in a modern browser.
4. Check keyboard navigation, focus visibility, labels and status messages.
5. Confirm the demo works offline and does not submit personal data.
6. Submit a pull request with a concise summary and manual test steps.

## Current scope
The current phase is frontend-only. Do not add a live database, authentication, payment flow, analytics tracker or external form submission without explicit project approval and an agreed privacy/security design.
