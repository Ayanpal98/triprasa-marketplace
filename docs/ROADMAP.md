# Triprasa Roadmap

This roadmap describes intended work, not completed capabilities or committed launch dates.

## Phase 1 — Repository and frontend prototype
- [x] Responsive static storefront concept
- [x] Client-side search, category filtering, sorting and demo basket
- [x] Local-only seller-interest preview
- [x] Product specification and repository guidance
- [ ] Cross-browser and keyboard accessibility pass
- [ ] Visual review at mobile, tablet and desktop breakpoints

## Phase 2 — Community and seller discovery
- [ ] Interview prospective producers and community organisations
- [ ] Confirm categories and eligibility criteria with participants
- [ ] Co-design consent, attribution, correction and removal processes
- [ ] Validate packaging, shipping, returns and seller net margins
- [ ] Establish baseline metrics and a privacy-conscious research process

## Phase 3 — Functional commerce MVP
- [ ] Choose architecture after requirements and capacity are validated
- [ ] Design database and access-control model
- [ ] Secure seller and admin authentication
- [ ] Catalogue, inventory and moderation workflows
- [ ] Order lifecycle, payments, refunds and settlement reconciliation
- [ ] Shipping, fulfilment, support, returns and audit logging
- [ ] Legal, tax, privacy and product-specific compliance review

## Phase 4 — Controlled Tripura pilot
- [ ] Recruit a small, consented seller cohort
- [ ] Train sellers and test assisted onboarding
- [ ] Test end-to-end fulfilment with real cost data
- [ ] Track completion, cancellations, returns, repeat purchases and net seller earnings
- [ ] Review results before expansion

## Phase 5 — Growth
- [ ] Wholesale and corporate gifting discovery
- [ ] National shipping readiness
- [ ] Export feasibility and product-specific compliance
- [ ] Multilingual and multi-currency support when operationally supported

## Release gate
Do not launch live transactions until seller consent, accurate listings, privacy, legal/compliance, payment, fulfilment, customer support, refund and security workflows have been tested.
